Aquí está el error

  1. Like Dogs: la solución reporta 0.17; el valor correcto es \(\frac14=0.25\). (El 0.17 es el Gini de Like Gravity en la raíz; parece haberse copiado.)

  2. Age: la solución dice que el mejor umbral es 45.5 (0.22, valor que sí es correcto). Pero el umbral 49 separa perfectamente (\(\{30,36,44,47,47\}\) son todos Sí y \(\{51\}\) es No): Gini \(=0\). Se omitió o se calculó mal.

  3. Por eso eligen Like Dogs (\(0.17<0.22\)) cuando lo correcto es \(\text{Age}<49\) (\(0<0.22<0.25\)).

Conclusión

El error no está en el primer árbol (umbrales \(27,33,36,39,\dots\)). Está en el nodo Like Gravity=Sí: Gini de Like Dogs \(=0.25\) (no 0.17), umbral \(\text{Age}=49\) con Gini 0 omitido, y ramas finales mal asignadas. El árbol correcto es: Like Gravity=No \(\Rightarrow\) No; Like Gravity=Sí \(\Rightarrow\) (\(\text{Age}<49\Rightarrow\) Sí, en otro caso No), con 100 % de exactitud en entrenamiento.

from fractions import Fraction as F

age   = [24, 30, 36, 36, 42, 44, 46, 47, 47, 51]
dogs  = [0, 1, 0, 0, 0, 1, 1, 1, 0, 1]
grav  = [0, 1, 1, 0, 0, 1, 0, 1, 1, 1]
astro = [0, 1, 1, 0, 0, 1, 0, 1, 1, 0]

def gini(ys):
    if not ys:
        return F(0)
    p = F(sum(ys), len(ys))
    return 1 - p**2 - (1 - p)**2

def split(ys_l, ys_r):
    N = len(ys_l) + len(ys_r)
    return F(len(ys_l), N) * gini(ys_l) + F(len(ys_r), N) * gini(ys_r)

def tabla(idx, nombre):
    print(f"\n== {nombre}: n={len(idx)}, Gini={gini([astro[i] for i in idx])}")
    vals = sorted({age[i] for i in idx})
    for a in [(u + v) / 2 for u, v in zip(vals, vals[1:])]:
        L = [astro[i] for i in idx if age[i] < a]
        R = [astro[i] for i in idx if age[i] >= a]
        g = split(L, R)
        print(f"  Age < {a:<5}  izq {len(L)} ({sum(L)}/{len(L)-sum(L)})  "
              f"der {len(R)} ({sum(R)}/{len(R)-sum(R)})  Gini_split = {str(g):>5} = {float(g):.4f}")
    for var, v in [("Like Dogs", dogs), ("Like Gravity", grav)]:
        L = [astro[i] for i in idx if v[i] == 1]
        R = [astro[i] for i in idx if v[i] == 0]
        if L and R:
            g = split(L, R)
            print(f"  {var:<12}  Gini_split = {str(g):>5} = {float(g):.4f}")

todos = list(range(10))
tabla(todos, "Raíz")
nodo_g = [i for i in todos if grav[i] == 1]
tabla(nodo_g, "Like Gravity = Sí")
tabla([i for i in nodo_g if dogs[i] == 1], "Like Gravity = Sí, Like Dogs = Sí")
